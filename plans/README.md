## Execution environment notes (learned during 001)

- **Agent worktrees branch from `origin/master`, not the current branch**
  (`worktree.baseRef` defaults to `fresh`). An executor worktree will NOT
  contain the `set-video-upload` code; reviewers must `git reset --hard
  <branch HEAD>` the worktree (or set `worktree.baseRef: head`) before the
  executor starts, or the plan's drift-check STOP will fire.
- **Windows MAX_PATH breaks vitest under `.claude/worktrees/`**: pnpm's
  virtual-store paths exceed 260 chars (`ERR_PACKAGE_IMPORT_NOT_DEFINED` for
  `#module-evaluator` at startup). Fix: `pnpm install --node-linker=hoisted`
  inside the worktree's `frontend/`. `--virtual-store-dir` to a short path
  does NOT work (breaks cross-package ESM resolution).
- **`pnpm lint` does not exit 0 at baseline**: commit `2556364` carries two
  pre-existing errors in `frontend/src/components/workout/set-state-cell.tsx`
  and `frontend/src/routes/today.tsx`. Plans' "lint exits 0" criteria should
  be read as "no NEW lint errors" until those are fixed.

## Findings considered and rejected

- **Editing `V1__001_init.sql` instead of adding a new migration**: looks like
  a violation of CLAUDE.md's "write a new Flyway migration" workflow, but git
  history shows merged PRs #7 and #9 did the same — consolidating into V1 with
  destructive dev clean-migrates is the de-facto pre-launch convention. Not a
  branch defect. Residual action (not planned): one line in CLAUDE.md noting
  the pre-launch convention, and switch to additive migrations at first
  persistent deploy.
- **Unused `apierr.Conflict` helper** (`backend/internal/apierr/problem.go:65`):
  three-line dead code; plan 004's maintenance notes name its intended future
  use (mapping same-set unique-violation races to 409). Not worth a plan.
- **`envInt`/`envInt64` silently fall back on parse errors**
  (`backend/internal/config/config.go:132-148`): a typo'd `MAX_VIDEO_BYTES`
  silently uses the default. Cosmetic for a single-operator app; revisit if
  config grows.
- **Stale `pending` set_videos rows never expire**: bounded in practice
  (replacement frees the per-set slot; per-user cap limits accumulation) and a
  janitor adds an operational component for negligible win at current scale.
- **Quota check-then-insert race (no `FOR UPDATE`)**: accepted; single-user
  blast radius, bounded by the `set_videos_setlog_uq` unique index. Documented
  in plan 004's maintenance notes.
- **Stray empty directory `frontend/src/services/generated;C`**: untracked
  junk (likely a mis-quoted command on May 30); flagged to the operator to
  delete manually — advisors don't mutate the tree.
