  `In()` with an empty slice yields a no-match, and the `total == 0` switch arm
  (`repository.go:352`) handles the empty case safely.
- **"Per-day video quota is timezone-buggy"** — by design. `repository.go:72` enforces a
  rolling 24h window, not a calendar day; `MAX_VIDEOS_PER_DAY` is documented as such.
- **"MarkReady/MarkFailed lack ownership checks"** — defense-in-depth only. Both are
  called solely from `Finalize`, which verifies ownership via `GetOwned(videoID, ownerID)`
  first (`videos/service.go:116`). No reachable IDOR. Not worth a parameter-threading change.
- **"Generic mapper abstraction across aggregates"** — not worth doing. The three mapper
  trees are similar but the shared-generic refactor is L effort for near-zero benefit and
  risks subtle nil/capacity differences. Revisit only if a 4th aggregate is added.

  all exist and are thorough. (`storage/r2.go` is untested, but it is a thin wrapper over
